# AdventureWorks 購買管理システム

## プロジェクト概要

本プロジェクトは、Clean Architecture と Domain-Driven Design を採用した WPF 業務アプリケーションの実装例です。AdventureWorks のサンプルデータベースを活用し、購買管理業務をモデル化したシステムを構築しています。

## アーキテクチャの特徴

- **Clean Architecture**: 依存関係の逆転による疎結合設計
- **Domain-Driven Design**: ドメインモデル中心の設計手法
- **MVVM パターン**: WPF に適したプレゼンテーション層の分離
- **MagicOnion**: gRPC ベースの型安全な RPC 通信
- **Dapper**: 軽量で高性能な Micro ORM
