# 作業履歴 2022-11-11

## 概要

2022-11-11の作業内容をまとめています。この日は **購入注文の複雑なビジネスロジック** を実装するために **Builder パターン** を導入し、ドメインモデルをより実用的なものに発展させた重要な日です。

### 主な作業内容

1. **PurchaseOrderBuilder の実装**

   - 複雑な購入注文作成処理をBuilder パターンで実装
   - 製品追加時の自動計算機能（小計、税額、送料）
   - リードタイム計算による納期自動設定

2. **値オブジェクトの拡張と演算子オーバーロード**

   - Date 型に日数加減算演算子を追加
   - Dollar 型に税率計算機能を実装
   - Gram 型の乗算演算子とExtension メソッド追加
   - DollarPerGram 型の新規導入（重量ベース料金計算用）

3. **ドメインモデルの改善**

   - Money から Dollar への名称統一
   - Vendor に TaxRate プロパティ追加
   - ShipMethod の料金体系を重量ベースに変更

4. **型安全性の更なる強化**

   - 通貨と重量の単位を明確に分離
   - 税率専用の TaxRate 型導入
   - ビジネス計算の型安全性確保

### アーキテクチャ上の意義

この作業により、**リッチドメインモデル** が確立されました：

- **Builder パターン**: 複雑なオブジェクト構築の責任分離
- **ドメインサービス**: ビジネスルールの凝集化
- **値オブジェクトの演算**: ドメイン固有の計算ロジック

### 実装されたビジネスルール

- **購入注文作成プロセス**:

  1. 従業員、ベンダー、配送方法、注文日の設定
  2. 製品追加時のベンダー製品情報検証
  3. リードタイム計算による自動納期設定
  4. 小計・税額・送料の自動計算

- **計算ロジック**:

  - 小計 = Σ(単価 × 数量)
  - 税額 = 小計 × ベンダー税率
  - 送料 = 配送料率 × 総重量

### 技術的成果

この日の作業で、単純な CRUD 操作から **ビジネスロジックを中心としたドメイン駆動設計** へと大きく前進しました。Builder パターンの導入により、複雑な購入注文作成が直感的で保守しやすいコードとして実装されています。

+namespace AdventureWorks.Purchasing;

+public class PurchaseOrderBuilder
+{
+    private readonly EmployeeId _employeeId;
+    private readonly Vendor _vendor;
+    private readonly ShipMethod _shipMethod;
+    private readonly Date _orderDate;
+    private readonly IList<(Product Product, PurchaseOrderDetail PurchaseOrderDetail)> _details = new List<(Product, PurchaseOrderDetail)>();
+
+    public PurchaseOrderBuilder(
+        EmployeeId employeeId, 
+        Vendor vendor, 
+        ShipMethod shipMethod, 
+        Date orderDate)
+    {
+        _employeeId = employeeId;
+        _vendor = vendor;
+        _shipMethod = shipMethod;
+        _orderDate = orderDate;
+    }
+
+    public void AddProduct(Product product, short quantity)
+    {
+        var vendorProduct = _vendor
+            .VendorProducts
+            .Single(x => x.ProductId == product.ProductId);
+        _details.Add(
+            (
+                product,
+                new PurchaseOrderDetail(
+                    _orderDate + vendorProduct.AverageLeadTime,
+                    product.ProductId,
+                    vendorProduct.StandardPrice,
+                    quantity)));
+    }
+
+    public PurchaseOrder Build()
+    {
+        Dollar subTotal = _details
+            .Select(x => x.PurchaseOrderDetail.LineTotal)
+            .Sum();
+        Dollar taxAmount = subTotal * _vendor.TaxRate;
+
+        Gram totalWeight = _details
+            .Select(x => x.Product.Weight * x.PurchaseOrderDetail.OrderQuantity)
+            .Sum();
+        Dollar freight = _shipMethod.ShipRate * totalWeight;
+
+        return new(
+            _employeeId,
+            _vendor.VendorId,
+            _shipMethod.ShipMethodId,
+            _orderDate,
+            subTotal,
+            taxAmount,
+            freight,
+            _details.Select(x => x.PurchaseOrderDetail).ToList()
+        );
+    }
+}
